# Security Policy — CrisisMesh

## 🇮🇹 Segnalare una vulnerabilità
- **Non aprire una issue pubblica.** Usa *Security → Report a vulnerability* (GitHub Security Advisory) oppure invia un'email riservata a fbxmano@gmail.com.
- Includi: descrizione dettagliata della vulnerabilità, passi di riproduzione, impatto sul protocollo (es. spoofing di nodi, replay attack, esaurimento risorse tramite flood mesh).
- Risposta entro **7 giorni**; coordinamento della patch e disclosure pubblica entro **90 giorni** dalla segnalazione.

## 🇬🇧 Reporting a vulnerability
- **Do not open a public issue.** Use *Security → Report a vulnerability* (GitHub Security Advisory) or email fbxmano@gmail.com.
- Include: vulnerability description, reproduction steps, attack vector, and potential impact on mesh routing (e.g. node spoofing, replay attacks, resource exhaustion via mesh flooding).
- Response within **7 days**; coordinated remediation and disclosure within **90 days** of the initial report.

## Versioni supportate / Supported versions
Solo l'ultima minor release stabile. / Latest minor release only.
